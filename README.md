# PCB-NFC-Card
A NFC card that pulls up the programmed website when tapped by a supported phone! It will also harvest the power from the NFC field to make an LED light up as well!

<img width="1072" height="503" alt="image" src="https://github.com/user-attachments/assets/5e465a94-8394-4cb8-9e22-17e510bc4750" />

# Why I made this:
I remember when I was a bit younger, this was before I got into making PCBs, that I always wondered how those little stickers would pull up a link on your phone when you tapped them. I thought that it was magic at that time. That was until I got into electronics and learned about NFC. Then, I questioned myself, can I make one of those myself? A little bit later, I luckily found a online tutorial teaching me how I can make one of those all by myself. It would even blink an LED without needing batteries! Then I made one that wll link to my GitHub page whenever a phone with NFC tapped it.
